# HTPC

## Philosophy: Appliance-Style, Controller-First

This folder documents the Lenovo M720q Tiny HTPC build meant to feel more like a Firestick or Xbox than a general-purpose Linux desktop. The goal is a simple, reproducible Bazzite KDE setup with Steam Big Picture, streaming launchers, controller support, cloning guidance, and recovery steps.
