# Physical Buildout

## Overview

Dedicated server closet framed in the basement, 42U open-frame rack, all cabling fished through walls with minimal drywall impact.

## Key Principles

- **Framed server closet** — dedicated room in basement, not a corner of the utility room
- **42U open-frame rack** — industrial, off-lease recommended (save $300–500 vs retail)
- **Fish cables, don't run conduit in walls** — conduit in walls is a massive drywall project; fish tape + flex bit does the same job with zero visible damage
- **Pre-wire everything before closing walls** — run camera cables even if cameras come later
- **Floor clearance and water protection** — basement flooding is real; plan for it from day one
- **Blueprint first** — annotate house blueprints before drilling anything

## Server Closet

- **Location:** Central basement, under a continuous interior wall (not under bathroom), away from plumbing, near electrical panel
- **Footprint:** 8'×6' minimum interior
- **Features:** 36" louvered door outward-swing, 3/4" plywood backer rear wall, sealed concrete floor, passive ventilation

## Rack Layout

- **Rack:** 42U open-frame (or enclosed for dust control)
- **Layout:** Network gear top, UPS middle, heavy servers low
- **Dell T30:** Tower form factor — on wire shelving beside the rack, not in it

## Cabling Approach

- No conduit inside walls
- Fish tape + 72" flex drill bit + glow rods for blind drilling
- Access from attic (down), basement (up), 2nd floor closet (lateral)
- Conduit only in exposed basement ceiling for organized cable management
